# Mark I

**Área:** Mecatrônica e dispositivos vestíveis · **Status:** programa de protótipos, ainda não implementado neste repositório.

**Mark I** é a primeira geração conceitual de uma **armadura vestível modular** inspirada em ficção científica. O objetivo não é reproduzir superpoderes, mas explorar mecanismos, sensores, eletrônica, conforto e integração de subsistemas reais.

## Direção

A primeira etapa será uma mão/antebraço experimental. Outros módulos de armadura dependerão de testes de viabilidade, custo, peso e segurança.

## Marcos pretendidos

- Especificar requisitos de conforto, tamanho, fixação e alimentação.
- Validar sensores e feedback visual/tátil em bancada.
- Testar articulações e movimentos seguros antes de vestir.
- Evoluir modelos CAD e documentação elétrica e mecânica.
- Integrar módulos apenas depois de testes isolados.

## Relação com outros projetos

O repositório **Manopla Inteligente** já contém experimentos de firmware, protocolo e laboratório 3D que poderão informar este projeto. Evitar duplicar código ou tratar uma simulação digital como dispositivo físico validado.

> Este repositório documenta a ideia de Mark I. Não existe armadura completa funcional; atuadores vestíveis exigem limites de força, parada de emergência e testes rigorosos.
